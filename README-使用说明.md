# TPoker 使用说明

德州扑克翻前"学练一体"训练器（PWA）。纯前端、完全离线：判分、间隔复习、统计全部在本机运行。v2.0 起新增：13×13 起手牌范围表、交互式范围题、进阶理论单元、全局范围速查页。

## 一、访问方式

### 主入口：GitHub Pages（推荐，任何网络可用）

地址：**`https://<你的用户名>.github.io/tpoker/`**（部署后见 P0 交付信息）

- 有网时打开一次，应用自动缓存全部资源；之后**离线/飞行模式也能用**。
- 为什么必须用这个入口：Service Worker 只在 HTTPS 下生效，旧的 `http://192.168.x.x` 局域网地址永远无法离线缓存——这是 v1"离开 Wi-Fi 打不开"的根因。

### 备用入口：局域网（仅开发调试）

- Windows：双击 `start.bat`；Mac/Linux：`bash start.sh`。
- 仅电脑本机测试（`http://127.0.0.1:8000/`）或同一 Wi-Fi 下的临时访问，**不具备离网可用性**。

## 二、iPhone 安装到主屏幕（必读）

1. iPhone 打开 **Safari**，访问上面的 GitHub Pages 地址。
2. 点底部**分享**按钮 → **"添加到主屏幕"** → 添加。
3. 之后**始终从桌面 TPoker 图标打开**（全屏、无地址栏、缓存最稳定）。
4. 首次从图标打开成功后，首页页脚会显示 **"离线就绪 ●"**——这代表缓存真正生效了。
5. 系统要求：iOS 16.4 或更高（旧系统的 Service Worker 行为不稳定）。
6. 首次离线使用前，必须在有网时从图标成功打开过一次。

## 三、内容 / 代码更新方法

更新全自动，无需手动清缓存：

1. 开发者推送新版本到 GitHub（内容更新会同步更新缓存清单与版本号）。
2. 你的 iPhone **有网时打开应用**（从图标或 Safari 均可）：检测到新版本后首页顶部出现 **"新版本已就绪 → 点击更新"** 横幅，点一下即自动刷新到新版。
3. **学习进度不会丢**（进度存在手机本机，与缓存分离）。

## 四、进度迁移（从旧的局域网版本迁过来，一次性）

不同网址之间的进度互不可见，需手动搬一次：

1. 在旧入口（局域网地址）打开应用 → 首页底部 **复盘统计 / 数据** → **导出备份 JSON**（发到微信文件传输助手或邮箱）。
2. 在新入口（GitHub Pages 地址）打开应用 → 同样进入统计页 → **导入备份 JSON** → 选择刚才的文件。
3. 看到"导入成功"即完成，全部进度、复习队列、统计原样恢复。

## 五、数据导出与备份

进度数据保存在浏览器本地存储（iOS 长期不用可能被系统清理，**建议每月导出一次**）：

- 打开应用 → 首页底部 **复盘统计 / 数据** → **导出备份 JSON**。
- 恢复：同页面 **导入备份 JSON**。非法文件（损坏 JSON、版本不符、缺字段）会明确报错，**不会污染现有数据**。

## 六、日常使用流程

1. **首页"今日待办"**：按提示进入下一个单元的学习卡（概念 → 规则 → **范围表** → 示例 → 进阶理论 → 常见误区 → 参考来源）。
2. 学完点 **开始测验**：本单元全部题 + 已掌握单元的交错旧题；**范围题**在 13×13 矩阵上点格子作答，每题即时判分附讲解。
3. 正确率 ≥ 85% 通过；答错自动进入复习队列（明天 → 3 天后 → 7 天后）。
4. 通过后第 3 天出现**回访测验**，再达 85% 该单元标记**已掌握**（变绿）。
5. 首页 **范围速查**：全部范围表一处翻阅，点任意格子看组合数与占比。

## 七、开发自测

- 内容校验：`python tools/validate_content.py --strict`（需 16 单元 273 题全绿）。
- 逻辑测试：`node tests/run-tests.js`；无 Node 可 `cscript //Nologo tests/cscript-run.js` 或浏览器打开 `tests/test.html`。
- 全量题库走查：`cscript //Nologo tests/t6-walkthrough.js`（273 题判分必须 100%）。
- 发版：`python tools/build_sw.py --bump`（刷新缓存清单 + 版本号），然后推送。

## 八、常见问题

- **打不开 / 一直转圈**：检查手机是否有网；确认访问的是 GitHub Pages 地址而非局域网地址。
- **换了手机**：新手机上安装后导入备份 JSON 即可。
- **"离线就绪"不出现**：确认是 iOS 16.4+、从主屏图标打开、且首次打开时有网。
